# Free Vehicle Maintenance Kit

A printable, fillable toolkit for tracking your car's maintenance, repairs, fuel, and mileage. No accounts, no sign-ups, no data collection—just open and use.

## What's Included

| File | Description |
|------|-------------|
| `service-log.md` / `service-log.html` | Record routine services (oil changes, tire rotations, fluid flushes, filter replacements, belts, battery, alignment, etc.) — 8 pre-filled rows + 12 blank rows |
| `repair-tracker.md` / `repair-tracker.html` | Track unexpected repairs: symptoms, diagnosis, parts, labor cost, total cost, shop, warranty status, invoice numbers — 20 blank rows + symptom reference guide |
| `fuel-mileage.md` / `fuel-mileage.html` | Log fill-ups with odometer, gallons/liters, price/unit, total cost, trip miles, calculated MPG/km/L, cost per mile — 50 rows + 12-month summary table |
| `maintenance-schedule.md` / `maintenance-schedule.html` | Manufacturer-recommended intervals (20 items) with checkboxes, last-done/next-due dates, custom items table, and 4-season checklist |

## Quick Start

### To Fill Digitally
Open any `.md` file in a Markdown editor (Obsidian, VS Code, Typora, etc.) and type directly. Edit the Markdown source to add/remove rows or change intervals.

### To Print
1. Open any `.html` file in a web browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Select "Save as PDF" or print to paper
4. For best results:
   - Enable **Print background graphics**
   - Set margins to **Minimum** or **None**
   - Print double-sided to save paper
   - Hole-punch and keep in your glove compartment or a binder

## Features

- **Fillable tables** — Ready to print or edit digitally
- **Print-optimized HTML** — Clean styling, proper page margins, checkboxes for tracking
- **Markdown source** — Fully editable in any text editor
- **No dependencies** — Works offline, no JavaScript, no build step
- **No tracking** — Zero data collection, zero accounts, zero external calls

## Customization Tips

- Add your vehicle's exact service intervals from the owner's manual
- Add/remove rows in the Markdown files to match your needs
- Change column widths in the HTML `<style>` section
- Print only the pages you need
