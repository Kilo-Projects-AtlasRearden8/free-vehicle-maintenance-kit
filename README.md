# Free Vehicle Maintenance Kit

A printable, fillable toolkit for tracking your car's maintenance, repairs, fuel, and mileage. No accounts, no sign-ups, no data collection—just open and use.

## Contents

| File | Description |
|------|-------------|
| `service-log.md` / `service-log.html` | Record routine services (oil changes, tire rotations, fluid flushes, etc.) |
| `repair-tracker.md` / `repair-tracker.html` | Track unexpected repairs, parts, labor, and costs |
| `fuel-mileage.md` / `fuel-mileage.html` | Log fill-ups, calculate MPG, track fuel costs over time |
| `maintenance-schedule.md` / `maintenance-schedule.html` | Plan and check off manufacturer-recommended intervals |

## Quick Start

1. **Print**: Open any `.html` file in your browser → Print (Ctrl/Cmd+P) → Save as PDF or print to paper
2. **Fill digitally**: Open `.md` files in any Markdown editor (Obsidian, VS Code, Typora, etc.) and type directly
3. **Customize**: Edit the Markdown source to add/remove columns, change intervals, or add your vehicle details

## Print Tips

- Use **Print Background Graphics** in your browser print dialog for best results
- Set margins to **Minimum** or **None** for maximum writing space
- Print double-sided to save paper
- Hole-punch and keep in your glove compartment or a binder
