**Service Type Codes:**
- OC = Oil Change
- TR = Tire Rotation
- BI = Brake Inspection
- FF = Fluid Flush (coolant, transmission, brake, power steering)
- FR = Filter Replace (air, cabin, fuel)
- BH = Belt / Hose Replacement
- BT = Battery Test / Replace
- AL = Wheel Alignment
- OT = Other

**Tip:** Write the next due mileage or date in the "Next Due" column so you never miss an interval.
